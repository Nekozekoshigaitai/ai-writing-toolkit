# AIライティングツール

Gemini APIを使った個人用のAIライティング支援ツールです。Streamlitのマルチページ構成で、
ブログ記事作成・メール返信作成・文章要約・文章校正・翻訳・タイトル案生成の6機能をまとめています。
データベースやログイン機能は使わず、個人のローカル環境で動かすことを想定しています。

## セットアップ

```bash
pip install -r requirements.txt
```

Gemini APIキーは以下のいずれかの方法で設定します。

- `.env` ファイルを作成し、`GEMINI_API_KEY=あなたのAPIキー` を記載する（`.env.example` を参考にしてください）
- アプリ起動後、左サイドバーの入力欄にAPIキーを直接入力する（ブラウザセッション内のみで保持され、保存はされません）

## 起動方法

```bash
streamlit run app.py
```

## 機能一覧

| ページ | 機能 |
| --- | --- |
| 📝 ブログ記事作成 | テーマ・読者・トーン・長さなどを指定してブログ記事の下書きを生成 |
| ✉️ メール返信作成 | 受信メールと伝えたい内容から返信文の下書きを生成 |
| 📄 文章要約 | 長文を指定した長さ・形式（箇条書き/文章）で要約 |
| ✅ 文章校正 | 誤字脱字・文法・敬語などをチェックし、修正案と変更点を提示 |
| 🌐 翻訳 | 日本語⇔英語など多言語間の翻訳 |
| 💡 タイトル案生成 | 記事内容から複数のタイトル候補を生成 |

## 技術スタック

- Python
- Streamlit
- Gemini API（`google-genai` SDK）
